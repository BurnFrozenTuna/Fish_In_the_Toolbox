음원 메타데이터 삭제

제목·작업자·앨범·커버 같은 음원 태그를 정리해요.

● 파일은 내 브라우저에서만 처리해요. 서버 업로드 · API 키 없이.

실험 기능 · 원본은 그대로 두고 새 파일로 저장합니다. 저장한 파일이 제대로 재생되는지 확인해주세요.

MP3 · WAV · FLAC · M4A

한 번에 1개 · 최대 512 MiB · 파일 내용과 확장자가 모두 지원 형식이어야 합니다.

파일을 선택해주세요.

정리한 파일 다운로드

다운로드 이름은 clean-audio / clean-video로 바뀝니다. 기기의 파일 생성·수정일은 새로 생길 수 있어요.

저장 전 재생 확인

삭제 범위

MP3: ID3v1/v2·APE 태그. WAV: PCM/float의 부가 청크. FLAC: 재생 필수 STREAMINFO 외 태그·커버 등. M4A: MP4와 같은 컨테이너 태그 정리.

MP4/M4A: udta·meta·UUID 태그와 여유 영역의 내용을 비우고 생성·수정 시각, 트랙 이름, 인코더 이름 필드를 정리합니다. 파일 크기가 그대로일 수 있어요.

음원·영상 자체, 워터마크, 비트스트림 내부 정보 및 일부 비표준 태그는 제거하지 않습니다. 코덱·길이·해상도 같은 재생 필수 정보는 남습니다. 완전한 익명화를 보장하는 도구는 아닙니다.

형식 참고 자료: ID3 · FLAC · MP4 / QuickTime
